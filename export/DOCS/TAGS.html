Crossword grid

crossword-grid

A rectangular crossword; its value is columns x rows.

across / down

Directional groups containing word, first-letters, and word-lengths.

word

Comma-separated crossword answers when nested under across or down (also used for glossary entries).

first-letters

Comma-separated starting (row,column) grid squares.

word-lengths

Comma-separated answer lengths.

across-clues / down-clues

Clues in the same order as the corresponding directional words.

See the crossword schema for an example and validation rules.

Ebook

ebook

Book root with a required content section. output selects HTML or plain-text compilation; mode controls optional style and script inclusion.

metadata

Bibliographic fields: title, subtitle, author, language, description, date, publisher, rights.

cover

Optional image and caption.

toc

Table of contents generated from headings in content.

content

The required body of an ebook.

heading / paragraph

Headings (with optional level and id) and body paragraphs within ebook content or sections.

title / subtitle / author / language / description / publisher / rights

Fields within ebook metadata; date also works there.

javascript

Interactive ebook script; script also works.

See the ebook schema for an example and output behavior.

survey

question

prompt

option

Creative-work records

film / song / album / book / series / episode / game / podcast

Records describing creative works. Each requires exactly one nonempty title; all accept optional description, release-year, and repeated genre fields. book describes a work; ebook contains its actual content for export. In a song, album is a scalar album-name field; elsewhere it is a record.

director

Film director credit. Repeat for multiple directors.

artist

Song or album artist credit. Repeat for multiple artists.

creator

Series, game, or podcast creator credit. Repeat for multiple creators.

release-year

Four-digit release/publication year of any creative-work record.

genre

A genre label on any creative-work record. Repeat for multiple genres; labels such as dark-comedy remain plain text.

season-number / episode-number

Episode numbering. Season numbers are nonnegative (0 for specials); episode numbers are positive integers.

The existing title and description fields also belong directly under any work record; author belongs under book, and publisher under book or game. start-year and end-year also belong under series; date also belongs under episode.

See the creative-work schema for field rules and complete examples.
